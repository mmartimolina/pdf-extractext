# pdf-extractext

Descripción 
Este proyecto fue diseñado para automatizar la extracción de texto desde documentos PDF. El propósito principal es optimizar el manejo de información digital, eliminando la necesidad de transcribir contenidos de forma manual y permitiendo que el procesamiento de archivos sea mucho más ágil y sencillo. 

Objetivos 
Nuestro enfoque es ofrecer una herramienta funcional que resuelva la captura de datos de manera eficiente. Buscamos transformar documentos estáticos en texto editable que pueda ser aprovechado para resúmenes, análisis o almacenamiento.

Funcionalidades Principales 
Extracción Automática: identifica y recupera el contenido textual de archivos PDF.
Optimización de Tiempos: facilita la conversión de datos sin intervención manual.
Preparación de Datos: entrega el texto limpio y listo para ser procesado por otros sistemas o modelos de IA.

Arquitectura del Sistema 
Nivel de Interfaz: es el punto de contacto  que recibe el archivo PDF y gestiona el inicio de la tarea.
Nivel de Procesamiento: es el motor del sistema, donde se aplica la inteligencia necesaria para convertir el archivo en texto.
Nivel de Almacenamiento: se encarga de gestionar la información resultante, permitiendo que el texto se guarde o se envíe a una base de datos.

Tecnologías Utilizadas 
Python: lenguaje base utilizado para toda la estructura del programa.
UV: gestor moderno que asegura que el proyecto tenga todas sus piezas en orden y funcione correctamente.
OpenCode: herramienta de asistencia basada en inteligencia artificial para el desarrollo del código.
MongoDB: sistema previsto para el almacenamiento organizado de la información en futuras etapas.

Guía de Ejecución 
python aplicacion/main.py nombre_del_archivo.pdf
